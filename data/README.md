# Data

## Source

This project uses the UCI Machine Learning Repository's **Online Retail** dataset.

- Dataset page: https://archive.ics.uci.edu/dataset/352/online+retail
- DOI: https://doi.org/10.24432/C5BW33
- Citation: Chen, D. (2015). *Online Retail* [Dataset]. UCI Machine Learning Repository.

## Local organization

Place downloaded files in the appropriate local subdirectory:

- `raw/`: original downloaded dataset
- `interim/`: intermediate data products
- `processed/`: model-ready data products

Raw and generated data files are excluded from Git by default. Keep the original source unchanged and document any derived dataset creation in the notebooks or source code.

No dataset files are included in this initial repository scaffold.
